Visual feedback for agentic coding.

A local-first MCP server and browser viewer that overlays a universal annotation system onto any agent-generated HTML.

Overview

Describing CSS bugs to an LLM is a frustrating game of telephone. markup solves the "visual feedback loop". Instead of writing prompts about pixels, you just look at the artifact, click, and type comments. `markup` anchors your comments to the UI and routes pixel-perfect screenshots of those specific regions back to the agent via the Model Context Protocol (MCP).

Key Features

Universal Overlay

Works on ANY HTML artifact without requiring you to bake feedback widgets or "copy prompt" buttons into your code.

Scroll Clustering

Automatically groups your comments based on what was visible in the viewport when you typed them.

Auto-Screenshots

Captures pixel-perfect screenshots of the clustered regions using a modern fork of html2canvas (color-mix supported).

Indefinite Long-poll

The MCP tool blocks indefinitely until you hit Cmd+Enter in the UI, keeping the agent paused until you're ready.

Quick Start

1

Install Globally

git clone https://github.com/async-ar15/markup.git
cd markup
bash scripts/install.sh

This installs dependencies and registers the server in your global claude.json.

2

Restart Agent

Restart Claude Code or your agent to load the new MCP tool.

3

Prompt the Agent

Ask the agent: "Build a dashboard and use the render_and_collect_feedback tool to show it to me."
