API Reference

MCP Tool

render_and_collect_feedback

Renders the supplied HTML in the viewer and blocks until the user submits annotated feedback.

html
string (required)
The full HTML document to render in the viewer. Must be self-contained (inline CSS/JS or CDN assets).
title
string (optional)
Short title for the artifact shown in the viewer's top bar.

Returns: Image content blocks (one per scrolled region) plus structured text describing the buckets.

HTTP Endpoints

GET /

Serves the viewer UI (index.html).

GET /artifacts/:id

Serves the raw HTML artifact by ID. This ensures the iframe is same-origin for html2canvas.

POST /submit

Receives the bundled feedback from the viewer.

POST /submit
Content-Type: application/json

{
  "artifactId": "uuid",
  "buckets": [...]
}

GET /health

Returns 200 OK if the server is running.

POST /debug-log

Accepts client-side errors and logs them to the server stderr.

WebSocket Protocol

Clients connect to ws://localhost:13847/ws. The server pushes artifact updates to all connected viewers.

artifact
JSON Message
{ "type": "artifact", "id": "uuid", "title": "Optional Title" }

The viewer automatically reconnects using exponential backoff if the connection is lost.

State Machine

stateDiagram-v2 [*] --> Idle Idle --> Pending : render_and_collect_feedback called Pending --> Resolved : User submits feedback Pending --> Rejected : Server shutdown Resolved --> Idle Rejected --> Idle

Submission Payload

interface FeedbackPayload {
  artifactId: string;
  buckets: Bucket[];
}

interface Bucket {
  // Pixel range [start, end] of the scrolled document
  range: [number, number];
  
  // All comments that fell into this region
  comments: Comment[];
  
  // Base64 encoded PNG of the rendered HTML in this region
  dataUrl: string;
}

interface Comment {
  id: string;
  text: string;
  scrollY: number;
  viewportH: number;
  timestamp: number;
}

Error Codes

Code Cause Resolution
PORTAL_BUSY Another MCP call is already pending feedback. Wait for the user to submit or cancel the previous request.
PORTAL_SHUTDOWN The server received SIGINT/SIGTERM while waiting. Restart the server and try again.
PAYLOAD_TOO_LARGE The submitted screenshots exceeded JSON limits. Increase max body size or submit fewer regions at once.
CONFLICT Submitted feedback for an artifact that is no longer pending. None. The previous submission was already processed.
