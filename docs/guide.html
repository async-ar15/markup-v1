Setup Guide

Requirements

  • Node.js 20+
  • Claude Code (or any MCP-compatible agent)
  • bash (for running the install script)

Installation

Option A: Global Install (Recommended)

Installs the tool at the user level so you can use it in any directory.

git clone https://github.com/async-ar15/markup.git
cd markup
bash scripts/install.sh

Option B: Per-Project Install

If you don't want a global install, you can add markup to your project's .mcp.json or claude.json manually.

{
  "mcpServers": {
    "markup": {
      "command": "npx",
      "args": ["-y", "tsx", "/absolute/path/to/markup/src/index.ts"]
    }
  }
}

Configuration

Zero config required by default.

Environment Variable Default Effect
MARKUP_PORT 13847 Sets the base port. If occupied, markup will try up to +5 ports automatically.
PORT none Fallback if MARKUP_PORT is not set.

Storage

All data is stored locally in your home directory at ~/.markup/

  • ~/.markup/artifacts/: The raw HTML files generated by the agent.
  • ~/.markup/feedback-<timestamp>/: The screenshots generated during a session.

Troubleshooting

MCP tool not found

Ensure you restarted your agent (e.g. type /mcp in Claude Code or restart the CLI) after running the install script.

Nothing renders / blank screen

Ensure your agent is generating valid, self-contained HTML. External stylesheets may fail to load if they don't support CORS.

1x1 Placeholder Image

If a CSS feature crashes html2canvas, markup falls back to a 1x1 transparent PNG to ensure the comments are still delivered. Check the browser console for rendering errors.

PORTAL_BUSY error

You have a pending artifact waiting for feedback. Submit or dismiss it in the browser before asking the agent to render another one.
